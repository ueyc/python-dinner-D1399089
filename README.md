## 問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**

`"4"` 是字串（str），只是「4 這個字元」，不是數量。Python 不能拿數字去除以字串，
`1220 / "4"` 會出現 `TypeError`；而字串的 `+`、`*` 是「接字串、重複字串」，例如 `"4" * 2` 會得到 `"44"` 而不是 8。
所以要先用 `int("4")` 轉成整數 4，才能做 `1220 / 4 = 305` 的分攤計算。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**

先扣折價券：1,200 − 100 = 1,100；服務費變成 1,100 × 10% = 110；應付總額 = 1,100 + 110 = **1,210 元**。
題目規定的算法是服務費以「原始餐費」計算：1,200 × 10% = 120，1,200 + 120 − 100 = **1,220 元**。
兩者差 10 元，原因是先扣折價券會讓服務費的計算基數變小（100 元的折價券也被少收了 10% 服務費），
因此計算順序不同，結果就不同。
